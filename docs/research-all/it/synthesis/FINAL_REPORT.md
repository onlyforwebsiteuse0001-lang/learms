## Major Findings for Learms

1. **Learning model:** Active, retrieval-based, project-supported learning has stronger evidence than passive content-only paths.
2. **Programming pain:** CS1 learners struggle with program construction, debugging, misconceptions, and compiler errors.
3. **UX:** Reduce cognitive load, provide progressive disclosure, make errors actionable, and follow WCAG/UDL.
4. **Pakistan:** IT export/workforce context is promising, but role/salary claims need current local evidence and confidence labels.
5. **Career guidance:** Role cards should include daily work, prerequisites, artifacts, salary evidence year, confidence, and transition paths.
6. **Tools:** Use browser playgrounds for low-friction starts, then transition to real Git/editor workflows.
7. **Security/privacy:** AI tutors, code execution, analytics, and cyber labs require Agent 3 review before implementation.
