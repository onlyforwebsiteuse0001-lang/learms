## Topic: Code review and collaboration are part of software quality
### Source: Jureczko, Kajda, and Górecki, 2020
### Key Finding: Code review effectiveness research studies review factors affecting defects and knowledge transfer.
### Relevance to Learms: Learners should practice pull requests, review comments, and small changes.
### Citation: https://doi.org/10.1049/iet-sen.2020.0134

## Topic: Classroom tooling can support authentic Git workflows but may change
### Source: GitHub Docs, 2026
### Key Finding: GitHub Classroom supports coursework workflows but docs note new sign-ups ended in May 2026 amid transition to partner solutions.
### Relevance to Learms: Learms should teach Git/GitHub concepts without relying exclusively on GitHub Classroom availability.
### Citation: https://docs.github.com/en/education/manage-coursework-with-github-classroom

## Learms Collaboration Progression

| Level | Tool/Workflow | Assessment |
|---|---|---|
| 1 | save versions manually | explain before/after |
| 2 | Git basics | commit small changes |
| 3 | GitHub repository | push project and README |
| 4 | Pull request | review and respond |
| 5 | Issue tracker | turn bug into issue and fix |
| 6 | Team project | branch/merge/review workflow |

## Product Requirements

- Teach commit messages as communication.
- Use small PRs for beginner review.
- Include code-review rubrics.
- Add conflict-resolution exercises only after Git basics.
- Export learner portfolio artifacts.
