## Topic: Software developer work is broader than writing code
### Source: O*NET, 2026
### Key Finding: O*NET lists software developer tasks such as analyzing user needs, determining feasibility, designing software, developing/testing procedures, documentation, and coordinating with others.
### Relevance to Learms: Career paths must teach communication, testing, documentation, and requirements, not only syntax.
### Citation: https://www.onetonline.org/link/summary/15-1252.00

## Topic: U.S. BLS data is useful as a global benchmark but not Pakistan salary evidence
### Source: BLS, 2025
### Key Finding: BLS occupational pages provide standardized U.S. pay/outlook data for software developers/QA, programmers, and systems analysts.
### Relevance to Learms: Use BLS for role definitions and global context, while Pakistan cards need local salary/job data.
### Citation: https://www.bls.gov/ooh/computer-and-information-technology/software-developers.htm ; https://www.bls.gov/ooh/computer-and-information-technology/computer-programmers.htm ; https://www.bls.gov/ooh/computer-and-information-technology/computer-systems-analysts.htm

## Learms Career UX Recommendations

- Show multiple realistic entry roles, not only “software engineer.”
- Each role card should include: daily work, first skill, hard parts, portfolio evidence, and transition options.
- Local salary confidence should be explicit.
- Career paths should include non-code and low-code IT roles for learners who discover programming is not their preferred path.
