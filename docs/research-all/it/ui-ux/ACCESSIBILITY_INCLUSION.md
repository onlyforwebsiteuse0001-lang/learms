## Topic: WCAG 2.2 should guide product accessibility
### Source: W3C, 2024
### Key Finding: WCAG 2.2 organizes accessibility around perceivable, operable, understandable, and robust principles; W3C advises using the most current WCAG version for applicability.
### Relevance to Learms: Learms should target WCAG 2.2 AA for learning content, exercises, dashboards, and auth flows.
### Citation: https://www.w3.org/TR/WCAG22/

## Topic: Universal Design for Learning supports learner variability
### Source: CAST, 2024
### Key Finding: UDL Guidelines 3.0 offer concrete suggestions for designing learning experiences accessible to diverse learners through engagement, representation, and action/expression options.
### Relevance to Learms: Learms should offer multiple ways to access explanations, practice, and demonstrate learning.
### Citation: http://udlguidelines.cast.org

## Learms Accessibility Checklist

| Area | Requirement | Source |
|---|---|---|
| Navigation | keyboard accessible, visible focus | S106 |
| Visual design | contrast, scalable text, not color-only | S106 |
| Content | captions/transcripts, alt text for diagrams | S106, S107 |
| Exercises | screen-reader-friendly code blocks and feedback | S106 |
| Assessment | alternative demonstration options where valid | S107 |
| Language | plain English plus glossary; Urdu/Roman Urdu support pending | S107 |
| Anxiety reduction | non-shaming feedback and retry paths | S088-S090 |
