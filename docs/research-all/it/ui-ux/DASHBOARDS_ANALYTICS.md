## Topic: Learning analytics dashboards can support self-regulated learning
### Source: Matcha, Uzir, Gašević, and Pardo, 2019
### Key Finding: A systematic review studied learning analytics dashboards from a self-regulated learning perspective, highlighting dashboard potential and design considerations.
### Relevance to Learms: Dashboards should help learners plan, monitor, and reflect, not merely display vanity metrics.
### Citation: https://doi.org/10.1109/TLT.2019.2916802

## Topic: Retrieval and distributed practice should appear in progress analytics
### Source: Dunlosky et al., 2013
### Key Finding: Practice testing and distributed practice are high-utility learning strategies.
### Relevance to Learms: Dashboard should show spaced-review due items and mastery over time.
### Citation: https://doi.org/10.1177/1529100612453266

## Topic: Dashboards can harm confidence if designed as shame systems
### Source: Rosenstein et al., 2020; Chen et al., 2024
### Key Finding: Impostor phenomenon affects CS students and can be linked with comprehension behavior/outcomes.
### Relevance to Learms: Avoid public rankings and punitive streaks for beginners.
### Citation: https://doi.org/10.1145/3328778.3366815 ; https://doi.org/10.1007/978-3-031-61569-6_2

## Learms Dashboard Metrics

| Metric | Good Use | Bad Use |
|---|---|---|
| Mastery by concept | diagnose weak area | rank against peers |
| Error patterns | target remediation | label learner as weak |
| Spaced-review due | plan retrieval | force endless streaks |
| Project milestone status | support planning | overwhelm with full roadmap |
| Time on task | spot stuckness | reward passive video time |
| Portfolio artifacts | career evidence | quantity over quality |

## Dashboard Views

1. Today: next action, review due, project blocker.
2. Concept mastery: foundations and prerequisites.
3. Error journal: top recurring bugs and remedies.
4. Portfolio: artifacts, evidence, review status.
5. Career readiness: role checklist with evidence freshness.

## Privacy Notes

- Minimize data collection.
- Explain why each metric exists.
- Allow private-by-default progress.
- Avoid selling/sharing learner performance without consent.
