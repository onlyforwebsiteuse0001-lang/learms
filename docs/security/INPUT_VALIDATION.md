# Input validation

Use Pydantic strict schemas and bounded lengths; parameterized SQL/SQLAlchemy only. Never concatenate SQL, shell commands, paths, HTML, or provider queries. Reject unknown JSON fields where practical. Encode output by context; sanitize deliberately allowed HTML with a maintained sanitizer and deploy CSP. State changes require CSRF token plus Origin validation. Disable XML external entities or avoid XML. SSRF defenses require scheme/hostname allowlists, DNS resolution checks, private/link-local/loopback blocking, redirect revalidation, and egress firewalling. Canonicalize paths and use server-generated names. Uploads need size/type limits, magic-byte checks, isolated ClamAV scanning, re-encoding, ZIP bomb limits, and storage outside webroot. Never unpickle untrusted data.
