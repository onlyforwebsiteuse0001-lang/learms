# Security operations

Monitor CVEs and threat feeds daily; scan dependencies/images on every change and weekly regardless. Triage critical/high findings within 24h/7d. On-call flow: detect, validate, classify, contain, eradicate, recover, notify, postmortem. Metrics: MTTR, patch compliance, aged criticals, MFA coverage, restore success, false-positive rate. Run quarterly tabletop and annual red/blue exercises. Security training and phishing simulations are tracked without punishing reported mistakes.
