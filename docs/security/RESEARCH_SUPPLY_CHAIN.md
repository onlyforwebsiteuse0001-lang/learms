# Supply chain research

Pin and hash dependencies, use private package allowlists, generate an SBOM, scan OS/Python dependencies, sign artifacts, and verify provenance before deployment. SLSA provides provenance maturity; Sigstore/cosign provides keyless signing and transparency. Builds should be isolated, reproducible, reviewed, and have no untrusted scripts with signing permissions. Source: [SLSA overview](https://slsa.dev/).
