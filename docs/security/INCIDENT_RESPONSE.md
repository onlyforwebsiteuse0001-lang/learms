# Incident response

1. Preserve logs and volatile evidence; open restricted incident record.
2. Assign incident commander, security lead, communications, and legal/privacy owner.
3. Contain using revocation, isolation, WAF rules, and least-privilege changes.
4. Eradicate root cause, rotate affected keys, rebuild from trusted artifacts.
5. Recover gradually with heightened monitoring and restore validation.
6. Notify affected parties/regulators through the approved legal process.
7. Complete blameless postmortem with control improvements and retest date.

Never delete evidence or disclose unverified speculation.
