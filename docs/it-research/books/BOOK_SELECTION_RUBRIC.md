- Status: Draft v0.1

## Topic: Book claims must be source-backed
### Source: User citation standard for Agent 5
### Key Finding: Book entries require author/year/ISBN/chapter/page where available; no source means write “not found.”
### Relevance to Learms: Prevents hallucinated reading paths and protects Agent 1 knowledge graph quality.
### Citation: Session instruction, 2026-09-30 UTC

## Rubric

| Criterion | Score 0 | Score 1 | Score 2 |
|---|---|---|---|
| Source verification | not found | metadata found via bookseller | publisher/official/library metadata |
| Edition clarity | no edition | edition inferred | edition explicitly verified |
| Learner level | unclear | approximate | mapped to prerequisites |
| Project alignment | none | general | module/project mapped |
| Pakistan accessibility | unknown | purchasable/imported | local/legal/free access verified |
| Currency | stale | timeless fundamentals | current or recently revised |
| Practicality | passive theory only | examples | exercises/projects |

## Learms Book Policy

- Prefer official publisher/library metadata over marketplace pages.
- Use marketplace pages only as temporary metadata and label them.
- Do not claim chapter/page content without a verified table of contents or source text.
- Tag books as beginner, intermediate, advanced, reference, or career.
- Add reading-time estimates only after chapter/page verification.

## Gaps

- Need official/library sources for all pending catalog items.
