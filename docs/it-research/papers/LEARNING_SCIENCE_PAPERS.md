# Learning Science Papers — Agent 5

- Status: Draft v0.1, Area 11 in progress
- Source anchors: S093-S096, S109-S110

## Topic: Active learning improves STEM outcomes
### Source: Freeman et al., 2014
### Key Finding: Active learning increased student performance in a meta-analysis across STEM contexts.
### Relevance to Learms: Avoid passive content-only design; embed active tasks in every module.
### Citation: https://doi.org/10.1073/pnas.1319030111

## Topic: Practice testing and distributed practice are high-utility
### Source: Dunlosky et al., 2013
### Key Finding: The review identifies practice testing and distributed practice as effective learning techniques.
### Relevance to Learms: Spaced concept/code/error reviews should be core product features.
### Citation: https://doi.org/10.1177/1529100612453266

## Topic: Deliberate practice informs mastery design
### Source: Ericsson, Krampe, and Tesch-Römer, 1993
### Key Finding: Expert performance is linked to prolonged, effortful, targeted practice with improvement goals.
### Relevance to Learms: Learms should diagnose weak skills and assign deliberate micro-practice.
### Citation: https://doi.org/10.1037/0033-295X.100.3.363

## Topic: Project-based learning needs support
### Source: Kokotsaki, Menzies, and Wiggins, 2016
### Key Finding: Project-based learning can be effective when designed with appropriate inquiry, support, and assessment.
### Relevance to Learms: Portfolio projects should have milestones, rubrics, and scaffolds.
### Citation: https://doi.org/10.1177/1365480216659733

## Topic: Cognitive load should shape UI and sequencing
### Source: Sweller, 1988
### Key Finding: High problem-solving load can interfere with schema acquisition due to limited working memory.
### Relevance to Learms: Progressive disclosure and worked examples matter for beginners.
### Citation: https://doi.org/10.1207/s15516709cog1202_4

## Topic: Dashboards can support self-regulated learning
### Source: Matcha et al., 2019
### Key Finding: Learning analytics dashboards have been reviewed from a self-regulated learning perspective.
### Relevance to Learms: Dashboards should support planning, monitoring, and reflection.
### Citation: https://doi.org/10.1109/TLT.2019.2916802
