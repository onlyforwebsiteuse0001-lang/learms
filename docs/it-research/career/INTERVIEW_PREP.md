## Topic: Hiring preparation should test role evidence, not memorization only
### Source: O*NET; SWEBOK; CS education sources
### Key Finding: Software developer work involves analysis, design, testing, documentation, and collaboration; programming education research shows novices struggle with independent program construction and debugging.
### Relevance to Learms: Interview prep should combine DSA, projects, debugging, testing, communication, and code review.
### Citation: https://www.onetonline.org/link/summary/15-1252.00 ; https://www.computer.org/education/bodies-of-knowledge/software-engineering ; https://doi.org/10.1145/572133.572137

## Learms Interview Prep Tracks

| Track | Content | Evidence Artifact |
|---|---|---|
| DSA | arrays, strings, maps, recursion, trees, graphs | solved problems + explanations |
| Debugging | read stack traces, isolate defects | bug journal |
| System design | APIs, DB, caching, queues | design doc |
| Project defense | explain architecture and trade-offs | portfolio walkthrough |
| Testing | unit/API/UI tests | test suite |
| Code review | review and respond | review transcript |
| Behavioral | teamwork/conflict/learning | STAR stories |
| Pakistan market | local stack/job-readiness | job-specific checklist |

## Beginner-to-Job Prep Ladder

1. Explain a small program line by line.
2. Fix a small bug with reasoning.
3. Build a feature from a short requirement.
4. Add tests and documentation.
5. Review someone else's code.
6. Deploy a simple app.
7. Explain trade-offs in plain English.
8. Practice role-specific interviews.
