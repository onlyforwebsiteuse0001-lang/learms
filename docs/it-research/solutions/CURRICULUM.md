## Topic: Learms curriculum should combine curriculum frameworks, workforce roles, and projects
### Source: ACM/IEEE-CS/AAAI CS2023; IEEE SWEBOK; ACM Data Science Task Force; NIST NICE
### Key Finding: Authoritative sources separately define CS competencies, software engineering knowledge areas, data science competencies, and cybersecurity workforce tasks.
### Relevance to Learms: Learms should build modular tracks that map from foundations to roles and capstone projects.
### Citation: https://csed.acm.org/ ; https://www.computer.org/education/bodies-of-knowledge/software-engineering ; https://dstf.acm.org/ ; https://doi.org/10.6028/NIST.SP.800-181r1

## Topic: IT/IS paths should not be forced into CS-only structure
### Source: ACM/IEEE-CS IT2017; ACM/AIS IS2020
### Key Finding: IT2017 emphasizes operational and integrative competencies, while IS2020 emphasizes organizational, data, technology, development, and integration realms.
### Relevance to Learms: Create separate pathways for IT operations, IS/business analysis, and software engineering.
### Citation: https://www.acm.org/binaries/content/assets/education/curricula-recommendations/it2017.pdf ; https://www.acm.org/binaries/content/assets/education/curricula-recommendations/is2020.pdf

## Curriculum Design Rules

1. Define outcome before technology.
2. Teach foundations just-in-time.
3. Prefer project milestones over isolated lectures.
4. Add security/privacy checkpoints in every track.
5. Show source freshness for market claims.
6. Include “exit ramps” to related careers.
