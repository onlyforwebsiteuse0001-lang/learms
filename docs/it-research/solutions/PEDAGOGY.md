## Topic: Active learning improves STEM performance
### Source: Freeman et al., 2014
### Key Finding: The PNAS meta-analysis found active learning increases student performance in science, engineering, and mathematics compared with traditional lecturing.
### Relevance to Learms: Learms should prioritize active tasks, quizzes, code tracing, debugging, and projects instead of passive video-only paths.
### Citation: https://doi.org/10.1073/pnas.1319030111

## Topic: Retrieval and distributed practice are high-utility learning techniques
### Source: Dunlosky et al., 2013
### Key Finding: The review identifies practice testing and distributed practice as among the most effective learning techniques.
### Relevance to Learms: Learms should use spaced recall for syntax, concepts, error patterns, commands, and security rules.
### Citation: https://doi.org/10.1177/1529100612453266

## Topic: Deliberate practice requires effortful targeted improvement
### Source: Ericsson, Krampe, and Tesch-Römer, 1993
### Key Finding: Expert performance develops through prolonged deliberate practice designed to improve performance under constraints.
### Relevance to Learms: Learms should use targeted drills on weak skills, immediate feedback, and progressively harder tasks.
### Citation: https://doi.org/10.1037/0033-295X.100.3.363

## Topic: Pair programming has conditional educational value
### Source: Salleh, Mendes, and Grundy, 2011
### Key Finding: Pair programming studies in CS/SE education generally report higher satisfaction and some assignment-performance benefits, but outcomes depend on student skill/context.
### Relevance to Learms: Learms can use structured pair tasks with role rotation and reflection, not random pairing.
### Citation: https://doi.org/10.1109/TSE.2010.59

## Topic: Project-based learning supports authentic learning but needs structure
### Source: Kokotsaki, Menzies, and Wiggins, 2016
### Key Finding: Project-based learning literature supports authentic inquiry and production but requires careful design, support, and assessment.
### Relevance to Learms: Learms should use milestone-based projects with rubrics, not vague “build anything” instructions.
### Citation: https://doi.org/10.1177/1365480216659733
