# StudyFlow Demo

A responsive front-end demo for a modern student learning dashboard.

## Run locally

No build step is required. Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Demo features

- Responsive sidebar and dashboard
- Course progress cards
- Daily study schedule
- Weekly activity chart
- Interactive focus-session notification

Built with plain HTML, CSS, and JavaScript so it is easy to preview and customize.
